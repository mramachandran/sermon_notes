# Master character list

Working order for the book. Every character gets the same four-page chapter. **M** = plenty of material, so use full lists. **S** = little material, so use shorter lists and Group notes space (see the style guide). Numbers set the file names and reading order.
**Totals:** 170 characters in 12 parts, 4 pages each (47 with plenty of material, 123 with little).
